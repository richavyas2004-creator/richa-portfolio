# Richa Vyas · Portfolio

A static site: plain HTML, CSS and JS. You don't need to build anything.

## Put it on GitHub Pages
1. Create a new public repository on GitHub, for example `richa-portfolio`.
2. Click **Add file → Upload files** and drag in **everything inside this folder**, including the `assets` folder and the hidden `.nojekyll` file. `index.html` must be at the top level.
3. Click **Commit changes**.
4. Open **Settings → Pages**. Under "Build and deployment" pick **Deploy from a branch**, then branch **main** and folder **/ (root)**, and click **Save**.
5. After about a minute your site is live at `https://<your-username>.github.io/richa-portfolio/`.

## Contact form
No setup needed. When a visitor fills in their name and email and clicks Send, Gmail opens in a new tab with a ready-to-send message addressed to richavyas2004@gmail.com. A link to open any other email app is shown too. No third-party form service is used, so nothing needs activating.

## Files
- `index.html`: home page (doors, timeline, Wall of Fame, contact)
- `case-study-1.html`, `case-study-2.html`, `case-study-3.html`, `teardown.html`, `work-samples.html`
- `assets/`: styles, scripts, images, PDFs, logos and certificates

## Google Drive links
The Work samples page links to your Drive files and folders. Visitors can open them only when each one is set to **Anyone with the link → Viewer**. Check the **Ad Creatives** and **Landing Page Copy** folders.
